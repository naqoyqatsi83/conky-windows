## What is Conky?

**Conky** is a free, light-weight system monitor for X, that displays any kind of information on your desktop. Originally built for Linux, this port brings Conky to **Windows 10/11** using **MinGW (GCC)** and the **Windows API** — no X server, no WSL, no Cygwin required.

The Windows port renders system information directly onto your desktop using a layered window with per-pixel alpha compositing, providing a native-looking desktop widget experience.

## Features

### Desktop Widget

- **Layered window** with per-pixel alpha compositing — integrates seamlessly with the Windows desktop
- **Transparent background** — only the text and graphics are visible
- **Configurable position** — top-right, top-left, bottom-right, bottom-left, or custom coordinates
- **Always-on-top** option via configuration
- **Click-through** — mouse events pass through to windows below

### System Monitoring

| Category | Objects |
|----------|---------|
| **CPU** | Usage per-core, frequency, temperature (via LibreHardwareMonitor), graph |
| **GPU** | NVIDIA GPU temperature, utilization, memory, fan speed, frequency (NVML) |
| **Memory** | RAM used/max/percentage, swap used/max/percentage, bars |
| **Storage** | Disk used/max/percentage per drive, bars, read/write speeds |
| **Network** | Download/upload speed per interface, total traffic, graphs, IP addresses |
| **System** | Uptime, hostname, process list (top-like), user info |
| **Temperatures** | CPU/GPU temperature via LibreHardwareMonitor fallback chain |
| **Lua scripting** | Extend with custom Lua scripts |

### More than 300 built-in objects

Conky can display a plethora of OS stats — from the basics (uptime, CPU, memory, disk, network) to advanced metrics (top processes, IMAP/POP3 mail, music player status, battery, weather, and much more).

For a full list, see the [Conky documentation](https://conky.cc/).

## Installation

### Quick Install (Recommended)

Download the latest installer from [GitHub Releases](https://github.com/YOUR_USERNAME/conky-windows/releases/latest).

1. Run `Conky-*-Setup.exe`
2. Follow the installer wizard
3. (Optional) Select **"Install LibreHardwareMonitor"** during setup for CPU/GPU temperature support
4. Conky starts automatically after installation

### Requirements

- **Windows 10/11** (x86-64)
- **Visual C++ Redistributable** (included with most Windows installations)
- **NVIDIA GPU** with [NVML](https://developer.nvidia.com/nvidia-management-library-nvml)-compatible driver (for GPU stats)
- **.NET Framework 4.8.1** — only if using LibreHardwareMonitor for temperature monitoring

### What Gets Installed

| Component | Purpose |
|-----------|---------|
| `conky.exe` | The Conky system monitor |
| `lhm-temp.exe` | Temperature helper (writes CPU/GPU temp to shared file) |
| `LibreHardwareMonitorLib.dll` | Hardware sensor library |
| `btop.conkyrc` | Sample configuration (installed to `%USERPROFILE%\Documents\Conky\`) |

### Uninstall

Via **Settings → Apps → Conky**, or right-click the Start Menu entry and select Uninstall. This removes:
- Conky executable and DLLs
- Scheduled task for temperature helper
- LibreHardwareMonitor files (if installed)
- Shared temperature data file

## Building

### Prerequisites

| Tool | Version | Download |
|------|---------|----------|
| **MinGW-w64 (TDM-GCC)** | g++ 10.3.0+ | [tdm-gcc.tdragon.net](https://jmeubank.github.io/tdm-gcc/) |
| **CMake** | 3.17+ | [cmake.org](https://cmake.org/download/) |
| **Lua** | 5.4.x | [luabinaries](https://luabinaries.sourceforge.net/) or build from source |
| **Inno Setup** | 6.x | [jrsoftware.org](https://jrsoftware.org/isdl.php) — for building installer |
| **NVML** | (bundled) | NVIDIA GPU driver development kit |

### Quick Build

```powershell
cd build
cmake -G "MinGW Makefiles" -DBUILD_NVIDIA_NVML=ON ..
mingw32-make.exe -j$(nproc) conky.exe
```

### Full Installer Build

```powershell
# 1. Build conky
cd build
cmake -G "MinGW Makefiles" -DBUILD_NVIDIA_NVML=ON ..
mingw32-make.exe -j$(nproc) conky.exe

# 2. Download LibreHardwareMonitor
cd ..\installer
.\download_lhm.cmd

# 3. Compile temperature helper
$csc = Get-ChildItem "C:\Windows\Microsoft.NET\Framework64" -Recurse -Filter "csc.exe" | Select-Object -First 1
& $csc -nologo -target:winexe -reference:LibreHardwareMonitor\LibreHardwareMonitorLib.dll -out:LibreHardwareMonitor\lhm-temp.exe lhm-temp\lhm-temp.cs

# 4. Build installer
& "$env:LOCALAPPDATA\Programs\Inno Setup 6\ISCC.exe" setup.iss
```

### CI Build

The repository includes a [GitHub Actions workflow](.github/workflows/build-windows.yml) that runs on `windows-latest` with MSYS2 MinGW:

- CMake configure + build
- Bundle runtime DLLs
- Download LibreHardwareMonitor
- Compile lhm-temp.exe
- Build installer with Inno Setup
- Upload artifact on every push
- Create GitHub Release on tag push (`v*`)

## Configuration

Conky looks for its config file in this order at runtime:

1. `%USERPROFILE%\.conkyrc`
2. `%APPDATA%\conky\conky.conf`
3. `%ALLUSERSPROFILE%\conky\conky.conf`
4. Built-in default (fallback)

Or specify a custom config:

```powershell
conky.exe -c "C:\path\to\my.conkyrc"
```

### Sample Config

The installer provides a sample config at `%USERPROFILE%\Documents\Conky\btop.conkyrc` (btop-inspired layout):

```lua
conky.config = {
  alignment = 'top_right',
  own_window = true,
  gap_x = 20, gap_y = 60,
  font = 'Consolas:size=10',
  default_color = 'white',
  update_interval = 1.0,
  minimum_width = 340,
  draw_shades = false,
}

conky.text = [[
${font Segoe UI:bold:size=12}${alignc}System Monitor
${hr 2}
...
]]
```

### Temperature Monitoring

Temperature is resolved through a fallback chain:

1. **LibreHardwareMonitor** (via `lhm-temp.exe` + named pipe / shared file) — best option, works with most modern CPUs and GPUs
2. **WMI query** — Windows Management Instrumentation (limited support)
3. **-1°C** — fallback when no sensor data is available

LibreHardwareMonitor is optional. Enable it during installation by selecting "Install LibreHardwareMonitor" in the installer.

## FAQ

**Q: Why Windows only?**
A: This is a Windows port of Conky. The upstream Conky already supports Linux, macOS, FreeBSD, and more. This fork focuses exclusively on Windows integration using native Win32 APIs.

**Q: Do I need WSL or Cygwin?**
A: No. Conky runs as a native Windows executable (conky.exe), built with MinGW (cross-compiler) and using only Windows system DLLs.

**Q: How is this different from the upstream Conky?**
A: The upstream Conky uses X11 or Wayland for display. This port replaces those backends with a native Windows layered window using GDI with per-pixel alpha. It also adds a Windows installer, LibreHardwareMonitor integration for temperature, and NVML bindings for NVIDIA GPU stats.

**Q: Why do temperature sensors show -1°C?**
A: LibreHardwareMonitor may not be running, or your hardware isn't supported. Make sure you selected "Install LibreHardwareMonitor" during installation, or check if lhm-temp.exe is running in Task Manager.

**Q: Can I run multiple instances?**
A: Yes, with different config files: `conky.exe -c config1.conf -d & conky.exe -c config2.conf -d`

**Q: Does it work on Windows 11?**
A: Yes, tested on Windows 11 Pro (build 22621+).
